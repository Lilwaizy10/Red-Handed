# Local face detection model

`blaze_face_short_range.tflite` is Google's pretrained BlazeFace short-range
float16 model, version 1. It is model data, not executable Python code, and is
bundled so normal monitoring never needs to download a model.

Source: https://storage.googleapis.com/mediapipe-models/face_detector/blaze_face_short_range/float16/1/blaze_face_short_range.tflite

Model documentation: https://developers.google.com/edge/mediapipe/solutions/vision/face_detector

The MediaPipe Authors provide the model under Apache License 2.0; see
`LICENSE.txt`. No camera images, video, face crops or user-derived model data
belong in this folder. See `docs/phase5_5.md` for the verified file digest and
MediaPipe Tasks telemetry disclosure.
